- Sizes from the design scale (`var(--sp-*)`), numbers in Hostwerk's language, the safety-net refresh pauses while the page is hidden. / Größen aus der Design-Skala, Zahlen in Hostwerks Sprache, Nachladen pausiert bei verstecktem Reiter.
- Minimum version Hostwerk 2.11 like the other templates; README with "Which template fits?". / Mindestversion 2.11 wie die anderen Vorlagen; README mit „Welche Vorlage passt?“.
- Release package contains everything except the repository tooling. / Release-Paket enthält alles außer Repo-Werkzeug.
